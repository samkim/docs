# Cloud Starter Program

The AuthZed Cloud Starter Program helps new users get started building authorization infrastructure while providing resources to scale with their growth.

## Program Benefits

The starter program provides valuable resources to help you get up and running:

- **$700 in Cloud credits** - Enough to run one permissions system with default configuration for one month
- **Schema design consultation** - Complimentary guidance from authorization experts to help you architect your permission system correctly from the start
- **Flexible timeline** - 30 days and $700 in credits give you sufficient runway to develop a real proof-of-concept
- **No upfront commitment** - AuthZed Cloud operates on a pay-as-you-go model, so you can continue using the service after your credits are used

## Eligibility

The Cloud Starter Program is available exclusively to new AuthZed Cloud users.

<Callout type="info">
  **Timeline:**
  Credits must be used within one month of receiving your program invitation.
</Callout>

## Getting Started

The starter program aims to help you build a solid foundation for your applications on authorization infrastructure. With expert guidance and cloud credits, you can:

1. Design and implement your schema with help from authorization experts
2. Build a complete proof-of-concept without financial barriers
3. Test AuthZed Cloud's capabilities with your real workloads
4. Scale confidently as your application grows
